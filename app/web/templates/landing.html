How AI DevGuard Works

1. Deterministic Rule & Shannon Entropy Scanner:

Runs high-precision regex pattern matching combined with Shannon entropy calculation. Sensitive keys are safely masked (AKIA****CDEF) before any LLM triage.

2. AST Semantic Code Navigation:

Parses Python stack traces and walks the Abstract Syntax Tree to identify enclosing functions, classes, and cross-file imported symbols.

3. Temperature-0 Structured Reasoning:

Feeds cleaned context into Google Gemini, OpenAI, Ollama, or configured cloud provider for structured JSON diagnosis.
